# The ceilings of the tree's checker: how many errors of each code each file may still have, per stage.
# A ceiling only falls. The compiler refuses a file over its ceiling (a missing row is a ceiling of 0), and
# [`build.ceilings_base`] refuses this file when it raises a count or adds a row, against the file at the merge
# base with main: CI runs it on every branch push and in the merge queue, and `bin/cosmic fix --check .` runs it
# wherever a base can be found. A code with no row left in any stage is closed ([`Ceilings.closed`]): this file
# cannot name it again, and a change that takes a code's last row adds it to that list. To lower a pin, remove the
# places it counts and lower the number, or delete the row at 0; never edit a number up.
