# 054 — bridge removal: regen, type generation, and docs publishing have no `--make` home

severity: blocker for 3i
type: gap (generation workflows)
area: `_types/cook.mk`, `_docs/cook.mk`, `mk/docs.mk`, planned `regen` verb

## what the bridge does today

- `bin/make regen-types` / `regen-tl-types`: run gentype/gentl against
  the pinned cosmos/tl to rewrite the committed `_types/*.d.tl`, with
  drift tests (`gentype_test`, `gentl_test`) failing on divergence.
  this is the **pin-bump workflow** — without it, a cosmos bump cannot
  be landed.
- `bin/make docs` / `doc-publish`: generate markdown docs into
  `o/docs` and publish them to the `docs` branch (docs.yml runs
  `bin/make -j doc-publish` with SOURCE_SHA).
- `bin/make facts`: regenerates `o/project.mk` — dissolves with the
  bridge (the graph is the facts).

## the gaps

1. **`regen` is planned, not built**, and it is the successor for the
   type-generation targets: `_types/` becomes generation units
   (`cosmo.gen.tl`, `tl.gen.tl` — the worked example in make-plan.md
   already draws this) run by `regen`. until it exists, retiring the
   Makefile orphans the pin-bump workflow entirely.
2. **the commit-or-generate decision for `.d.tl`.** the design says
   generated outputs are never committed, which means un-committing
   `_types/*.d.tl` — and accepting the recorded cost (a fresh clone
   cannot read `cosmo.*` types without building; editors need `o/` on
   the include path). the alternative — keep them committed with the
   byte-drift test, regenerated by `regen` — preserves today's
   ergonomics at the cost of one documented exception to the rule.
   either is coherent; pick one *in the design docs*, not by default.
3. **`doc-publish` pushes to a git branch** — a git operation, which
   the verb vocabulary deliberately cannot express. the coherent split:
   `--make` (or a generation unit) produces `o/docs/**`; the *push*
   stays a workflow step in docs.yml. say so, so nobody tries to give
   the build a git verb.
4. **generation-unit fencing** — a `regen`-run unit is the first real
   consumer of the in-process gate on non-Landlock hosts (the design's
   doubled enforcement); 052's fence work and this share a milestone.

## exit criteria

a cosmos pin bump lands using only `bin/cosmic` + `--make` verbs
(fetch → regen → test), and docs.yml publishes from a `--make`-produced
`o/docs`. the `.d.tl` decision is recorded in make.md's table.
