## Goal

G3 — an honest type layer, no escape hatches. This container moves the
honesty one layer down: the `cosmo.*` C contracts themselves become
exact, so the generated types stop declaring unions no correct caller
can reach and the cosmic side stops needing to dispose of them.

## The decision

A binding's return admits nil exactly when a CORRECT caller can meet
the failure at runtime — bad data or a changed environment. An
argument-shape error (a degenerate input no correct program passes:
zero or all-nil components to `path.join`, an invalid clock id to
`clock_gettime`) raises through the standard Lua bad-argument grammar
instead of returning `nil, err`.

Both halves of that rule already have upstream precedent, so this is a
completion, not a reversal: issue #151 converted data-dependent
throwers TO `nil, err` (`tool/lua/test_lfuncs_errors.lua` pins
DecodeHex, Inflate, GetCryptoHash), and `path.join` already raises on
zero arguments while returning nil on the equivalent all-nil call —
the inconsistency this container deletes.

What it replaces: the assert dance. D23 (amended 2026-08) licenses a
`cosmic.*` module to `assert` a binding return whose declared `| nil`
is unreachable for the arguments passed, carrying an `-- assert: <why>`
comment. cosmic PR #1385 (`cosmic/time.tl`, five sites) and PR #1386
(`cosmic/fs/path.tl`, one site) are that shape, landed as the interim
fix. The dance's cost is structural: the unreachability argument lives
as prose comments nothing machine-checks, invalidated silently by any
pin bump. With exact contracts there is nothing to assert away — the
claims move upstream into C behavior pinned by conformance probes.

## Win condition (observable)

- `o/_types/types_gen/cosmo/path.d.tl` declares `join(...): string`
  and `o/_types/types_gen/cosmo/unix.d.tl` declares
  `clock_gettime(clock?: integer): integer, integer` — no `| nil`
  slot 1 (today both carry it; regenerated by any cosmic build after
  the pin bump).
- `grep -rn -- '-- assert:' cosmic/time.tl cosmic/fs/path.tl` reports
  0 lines (6 once #1385/#1386 are both on main).
- Every remaining first-slot `| nil` in the definitions blocks of the
  modules cosmic wraps is classified by the census child: environmental
  (kept, uniform `T|nil, err, errno` tuple) — none degenerate-input-only.

## Children

- path.join raises on all-nil (whilp/cosmopolitan) — DONE, PR #276
- clock_gettime raises on an unsupported clock (whilp/cosmopolitan)
  — DONE, PR #277
- census of degenerate-input unions and tuple-shape deviations
  (whilp/cosmopolitan, research — decomposed into per-namespace
  children; each seeds contract-fix captures)
- cosmic consumes the exact contracts: pin bump + assert retirement
  (whilp/cosmic, unblocked once the two contract slices merged)
- the binding contract doctrine, written where binding authors read
  (whilp/cosmopolitan — makes the rule outlive this container)

## Batching the census's fixes

Census-driven contract fixes BATCH: raise-candidates confirmed by one
namespace walk land as one or a few upstream PRs per wave, and cosmic
consumes a wave with ONE pin-bump slice modeled on the existing
consumption child — never one pin bump per binding. A wave's consume
slice re-runs the same acceptance shape: regen'd `.d.tl` spot-checks,
`-- assert:`/guard retirements in the wrappers the wave frees, ci, and
the perf compare gate against the previous pin.

## Mechanics that bind every child

- A contract change lands C + `tool/net/definitions.lua` in the SAME
  commit (cosmopolitan AGENTS.md), with a conformance probe added in
  `tool/lua/test_definitions_conformance.lua` in the same PR.
- Every push to cosmopolitan master publishes a release
  (`YYYY.MM.DD-<short-sha>`); cosmic consumes by bumping
  `3p/cosmos/cosmos_pin.tl` — that bump plus the compare gate is the
  cosmic-side child, never folded into an upstream slice.
- The strict nil-flow endgame (3IPXRRd2) is unchanged by this
  container and still runs last; exact contracts shrink what its
  sweeps must guard, which is why this container outranks the
  remaining sweep slices.
