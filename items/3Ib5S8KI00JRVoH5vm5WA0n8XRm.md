## Change

Bump the board branch's `bin/cosmic.pin` to the release main already
pins, and regenerate `.cosmic-coverage` with the new toolchain — the
two land together because the gate cannot pass with either alone.

Measured 2026-08-29: the board's pin is
`2026-08-17-f421fa1` / sha256 d00aef83ff714163da06e1457c3274008832a9d8956e015e8c4ee69664cca46f;
main's is `2026-08-27-555873e` / sha256
145057b9fe905bb866fa3c03818265e4284a3bcd8367b76d9d5254f3c32a0900.
Under the board's current pin `require("cosmic.shape")` fails
`module not found: 'cosmic.shape'`. Under the NEW pin, a cold gate
run reproduces `coverage ratchet: literal: a coverage baseline must be
exactly \`return { … }\`` — the newer coverage tool reads the baseline
as a Lua literal, and the board's committed `.cosmic-coverage` is
still the old plain-column format (main's was already converted).
Every other stage passes cold under the new pin (fmt, check, lint).

The change, two files, nothing else:

1. `bin/cosmic.pin`: url line
   `url = https://github.com/whilp/cosmic/releases/download/2026-08-27-555873e/cosmic-lua`,
   sha256 line
   `sha256 = 145057b9fe905bb866fa3c03818265e4284a3bcd8367b76d9d5254f3c32a0900`
   — both fields together.
2. `.cosmic-coverage`: regenerated by the new toolchain itself —
   after the pin edit, delete `o/`, `bin/cosmic --make fetch`, then
   `bin/cosmic --make coverage --baseline` — and committed as the
   tool wrote it, never edited by hand. Read the regenerated rows
   against the old file: every module present before must be present
   after (a VANISHED row is a bounce, a re-measured number is not).

Then prove the toolchain: from that same cold state, run
`bin/cosmic --make ci` and read `ci: PASS` — the pin decides which
fence and checker the gates run under, so the whole gate under the
new pin IS the acceptance.

## Non-goals

No `_work/**` changes ride along — if the new toolchain's gate
refuses existing machinery CODE (any stage but the coverage-baseline
format), that is a bounce naming what broke, not a fix-up in this
diff. `.cosmic-coverage` is written only by `--make coverage
--baseline`, never by hand.
