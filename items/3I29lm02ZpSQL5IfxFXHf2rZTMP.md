## Goal

G8 — the flow system. `work:check` means "awaiting a planner verdict", and
review.md's first criterion is that CI is green on the PR's CURRENT head. That
criterion is checked by a human-equivalent read today, after a planner has
already spent a review round. The board tool already reads the PR — #1216
landed `_work/verdict.tl` and the `RawPull.head.sha` field that makes the head
knowable — so the one fact a reviewer needs before starting is one API call
away and is not being asked for.

## Change (to be settled in refinement)

Teach the board tool the one additional question about an issue's PR: what did
the head's checks conclude?

1. `_work/github.tl`: add a check-runs read for a head sha
   (`GET /repos/R/commits/SHA/check-runs`), returning each run's `name`,
   `status` and `conclusion`. `RawPull.head.sha` already exists from #1216.
2. `_work/verdict.tl` (or its neighbour): fold those into one standing answer —
   green / failing (naming the failed lanes) / in progress / absent.
3. `move N check` REFUSES when the head's checks have already concluded
   failure, naming the failing lane and the head sha. An in-progress run is NOT
   refused: review.md already tells the planner to review the next card and come
   back, and blocking the move would idle the implementer lane for the length of
   a CI run.
4. `show N` and `next --role planner` print the head's check status beside the
   standing verdict, so a planner never opens a red card by surprise.

The refinement pass settles: whether "required checks" means all five lanes or a
named subset; what happens when no check run exists yet at move time (the common
race — the move lands seconds after the push); and whether the refusal carries
an override for the deliberate "review this despite red" case.

## Non-goals

No auto-merge and no change to the accept-comment contract. No general
PR-reading surface — this is the second single question the tool asks about a
PR, in the same spirit as #1216's "what verdict stands". No refusal on an
in-progress or absent run. No change to the WIP limits or to which phases exist.
