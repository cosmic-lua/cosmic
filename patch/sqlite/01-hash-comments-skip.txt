note: cosmic.json reads `#` line comments when asked (`hash_comments`, patch/yyjson/), so a text can be both JSON5 and YAML's flow style. SQLite's JSON functions read JSON5 always, with no flags to ask by, so its reader takes `#` comments always too: `#` is never valid JSON outside a string, so no text that read before reads differently. A `#` comment ends where SQLite's own `//` comment does: a line feed, a carriage return, U+2028, U+2029 or the text's end. This record teaches json5Whitespace, which every JSON5 whitespace run is measured by, to skip one; the next sends the parser to it on a `#`.
