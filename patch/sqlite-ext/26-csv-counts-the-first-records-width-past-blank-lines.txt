note: With neither columns= nor schema=, the table's width is its first record's field count, and a blank line before the first record counts as a record of one field: a file that begins with a blank line is one column wide, and 22-csv-refuses-a-wider-record.txt then refuses its header. This counts the first record that is not a blank line (25-csv-reads-a-blank-line-as-nulls.txt), which is where cosmic.csv's readers find the header. Upstream counts the blank line as of 3.54.1.

--- replace
      nCol = 0;
      while( 1 ){
        csv_read_one_field(&sRdr);
        if( nCol==0 && sRdr.n==0 && !sRdr.bQuoted && sRdr.cTerm=='\n' ) continue;
        nCol++;
        if( sRdr.cTerm!=',' ) break;
      }
