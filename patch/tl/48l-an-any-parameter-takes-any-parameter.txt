note: a parameter expected as `any` is satisfied by a function of any parameter type there: `any` is the unchecked type in this tree, and the standard library declares its callbacks with it (`coroutine.create` takes `function(any...): any...`, a `__call` metamethod `function(any...)`), so `coroutine.create(function(a: string, b: integer) end)` and `setmetatable(o, { __call = function(self, a: string) end })` stay accepted where 48a would ask the parameter to accept anything. Only the expected type being `any` is looked at: a function expected to take a `number` is still not satisfied by one taking an `integer`
