note: a call dispatched through a `__call` metamethod does not end a block, whatever type the metamethod is declared: the function a metatable holds is attached at run time and checked against nothing, so a record declared with a never `__call` may be given one that returns (`setmetatable({}, { __call = function() end })`). Method calls on records and calls of function fields keep 40f1

         if not (func is FunctionType or func is PolyType) then

--- replace
         local via_call = false
         if not (func is FunctionType or func is PolyType) then
            local called = self:to_structural(func)
            via_call = not (called is FunctionType or called is PolyType or called is GenericType)
            func, is_method = self:resolve_for_call(func, args, is_method)
--- end
