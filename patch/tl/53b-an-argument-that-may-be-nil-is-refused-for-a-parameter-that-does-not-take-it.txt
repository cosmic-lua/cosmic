note: refuses, for every call, an argument that is a union carrying nil, or a nil, where the parameter does not take nil, since the callee raises or misbehaves when it is nil. The check is the call's own, by the parameter's type, whatever the callee is called: a local named `table` and an alias (`local ins = table.insert`) are checked like any function. It covers the parameters the call cannot omit (`call_min_arity`, exact since 53a) and every element of a varargs parameter (`...: T`). A parameter that is optional (`name?: T`), `any`, a union with nil, or a type variable not yet bound takes nil, and so does a type variable bound by the arguments before it to a type that takes it. It is an error and no warning because every warning cosmic sees is a refused compile (build/compilation.tl's `generate`, build/standalone.tl and build/example_checks.tl each reject on one) and the compile cache keeps no warnings to show again on a hit. A call whose special handler does not check its arguments (`require`) is not seen here; 53e checks that one
