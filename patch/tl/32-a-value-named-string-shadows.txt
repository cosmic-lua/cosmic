note: a variable, argument or loop variable named for a simple type was never checked for shadowing, since the name also spells a type; but `string` is the string library too, and `local string = s:upper()` hid it with no warning while every other library's name warns. A value so named is now checked against a record of that name, which only the string library is (`any`, `thread` and `userdata` are interfaces no value hides); a type declared with such a name warns as before
--- find
      if simple_types[new_name as TypeName] then
         if t.typename ~= "typedecl" then
            return
         end
      else
--- replace
      if simple_types[new_name as TypeName] then
         if t.typename ~= "typedecl" then
            old = self:find_var(new_name, "check_only")
            local hidden = old and old.t
            if not hidden or not (hidden is TypeDeclType) or hidden.def.typename ~= "record" then
               return
            end
         end
      else
--- end
