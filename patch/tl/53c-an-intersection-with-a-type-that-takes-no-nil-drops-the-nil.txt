note: the type a variable has where two facts hold at once (the else of `x == nil`, say, and of `x == ""`) is the intersection of the types they give. nil is a subtype of every type, so a union's nil member survived an intersection with a type that does not take nil (`string` with `string | nil` was `string | nil`), and a value tested against nil, then against a string, was nil again in the branch where both tests failed: `if x == nil then ... elseif x == "" then ... else f(x) end` refused `f(x)` for a parameter that does not take nil. The nil member is now dropped unless the other type takes it
