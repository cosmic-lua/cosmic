note: the first parameter of a function-typed record field is the receiver, and may be narrower than the field declares, when the type it is expected to be is a record or an interface (the record that holds the field, or an interface it implements) and the actual one is a record or interface too: an implementation is declared `read: function(FromStringReader, ...)` for an interface's `read: function(Reader, ...)` and is called with the record that holds it (`r:read()`), so the narrower receiver is the one it is given. A first parameter that is any other type (a number, a string, a union; `any` is 48l's), every other parameter, and the first of a function that is not a field's stay contravariant (48a), so `Opts.cb: function(number)` is not implemented by `function(n: integer)`. The convention is trusted, not checked: a call that names another receiver (`r.read(other, 1)`) type-checks, as it does without this record
