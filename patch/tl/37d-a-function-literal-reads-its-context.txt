note: a function literal checked where a function type is expected -- a call's argument, a declared local, an assignment, a table field, a return -- reads that type (37c): each parameter it leaves untyped takes the expected parameter type at its position, which is the type the callee calls it with, and an omitted return list takes the expected returns. Teal set only a `self` parameter's type so, and gave every other untyped parameter `any` and an omitted list no values, so `each(function(k) return k == "dir" end)` checked nothing of k and refused the return. A parameter past the expected ones, a `...` not at the expected vararg's position, a `self` type, and a type or return list holding a type variable not yet bound stay as before. Not in lax mode, which gives untyped parameters `unknown` for .lua files
