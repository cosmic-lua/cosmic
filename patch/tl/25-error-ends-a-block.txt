note: a call to the standard `error` never returns, so a block ending in one ends the way a `return` does and `if e == nil then error(trouble) end` narrows e below it. Only a call spelled `error` whose type is the standard library's own function (see 24b) counts: a local of that name with another type carries no handler, and another variable merely holding error is not trusted to keep holding it: only the global, scope 1, or a `<const>` local, since `local error = error` carries the handler too and could be assigned another function after
